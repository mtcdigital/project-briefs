# Project Briefs

Shareable, plain-English catch-up pages for projects Everett collaborates on.

Generated by the `/summarize` Claude Code skill.

- Each project gets a folder with an unguessable suffix.
- `index.html` in that folder is ALWAYS the latest version — that's the link you share.
- `versions/` holds every previous version, frozen, as an audit log.
- `history.json` is the machine-readable audit log.

These pages are `noindex` + `robots.txt` disallowed. Unlisted, not secret.
